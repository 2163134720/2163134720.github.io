四、结论分析与体会

实验结论分析

本次实验成功基于 Hexo 搭建本地博客并通过 GitHub 实现公网访问，核心结论如下：
1）Hexo 可将 Markdown 格式的博客内容转化为 HTML/CSS/JS 静态网页，借助 Node.js 的运行环境能快速完成本地预览；
2）Git 作为文件传输工具，实现了本地静态文件向 GitHub 仓库的推送，而 GitHub Pages 功能则将仓库文件托管为可公网访问的网页，解决了本地服务器依赖、博客无法持久访问的问题；
3）环境配置（如 SSH 密钥、路径参数）和依赖安装（如模板解析器）是确保博客正常渲染和部署的关键，配置错误会导致样式异常或部署失败。

实验体会

通过本次实验，我清晰理解了本地开发工具（Hexo/Node.js）、版本控制工具（Git）与云平台（GitHub）的协同逻辑，认识到静态网页生成与云端托管的核心原理。实操中也体会到配置细节的重要性，小到路径符号、依赖安装，大到仓库命名、Pages 配置，都直接影响最终效果，也让我掌握了从本地开发到公网发布的完整流程，提升了对 Web 部署基础逻辑的理解。
